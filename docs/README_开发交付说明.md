# 小小成长家｜开发交付说明

本目录包含：
- `01_前端设计开发文档.md`：页面、设计系统、交互、组件、路由、状态、接口与前端验收。
- `02_后端架构开发文档.md`：领域模型、数据表、API、AI 解析、积分与兑换事务、安全、部署与后端验收。

## 推荐交给 Codex 的启动指令
请阅读本目录全部 Markdown 文档，先输出前后端实施计划与 OpenAPI/数据库迁移草案，确认字段和状态机一致后开始编码。按 M1-M5 迭代，优先实现可运行的真实闭环。不要用前端假数据冒充后端完成；不要绕过家长审批；所有积分和兑换操作必须服务端事务化、幂等且可审计。每个里程碑完成后运行测试，提交可复现的启动命令和验收结果。
